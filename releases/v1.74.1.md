`alpine:latest` only: 57 passed, 1 failed of 58. debian:stable-slim and ubuntu:latest both green.

`aborted()` in `claude/whitebox-audit.sh` invoked `/usr/bin/grep`. Alpine's grep is busybox at
`/bin/grep`, so the call exited 127 on every invocation — always false — and an aborted scanner
was classified as a finding. **That is the exact defect 1.74.1 exists to fix, shipping unfixed on
one of the three supported platforms.** The absolute path was chosen on macOS to dodge an
interactive shell that shims `grep` to `ugrep`; dodging one platform's shim by hardcoding that
platform's path is how the bug got in.

The tag stays where it is. Nothing was published under it, `releases/README.md` records it as red,
and the fix ships as 1.74.2 with the same lane run again from the start.
